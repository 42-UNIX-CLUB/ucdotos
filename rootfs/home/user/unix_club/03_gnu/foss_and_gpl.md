# Free software & the GPL

  $ cat COPYING

# the four freedoms

  0  run the program, for any purpose
  1  study it & change it (needs the source)
  2  share copies
  3  share your modified versions
  # numbered 0-3. zero-indexed, of course.

# GPL versions

  * 1989  GPLv1
  * 1991  GPLv2: the Linux kernel, to this day (GPLv2-only)
  * 2007  GPLv3: adds anti-tivoization (you must be able to run your
          modified version on the device) and explicit patent
          protection
  # Linus declined v3: he disagreed with the anti-tivoization rule

  free as in speech, not as in beer
  FOSS = free and open-source software
