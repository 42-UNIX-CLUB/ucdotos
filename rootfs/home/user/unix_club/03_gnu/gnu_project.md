# The GNU Project

  $ info gnu

  > 27 Sep 1983: Richard Stallman announces GNU, a complete
    UNIX-compatible OS made only of free software
  > GNU = "GNU's Not Unix", a recursive acronym
  > 1985: the Free Software Foundation (FSF) is founded
  > by the early 90s: compiler, shell, editor, C library,
    coreutils... everything except a finished kernel
  > the kernel, GNU Hurd: "arriving next year", since 1990
