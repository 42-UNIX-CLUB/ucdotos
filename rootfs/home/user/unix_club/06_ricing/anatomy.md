# Anatomy of a rice

  $ cat anatomy.md

  1 window manager   i3, Hyprland, bspwm... tiling or floating
                     (or a full DE: GNOME, KDE)
  2 compositor       transparency, blur, shadows, animations
  3 bar              polybar, waybar
  4 launcher         rofi, wofi, dmenu
  5 terminal         kitty, alacritty, foot
  6 prompt           starship, powerlevel10k
  7 colourscheme     gruvbox, catppuccin, nord...
  8 font             Nerd Fonts: icons inside your font
  9 fetch            fastfetch (neofetch retired in 2024: "Have taken
                     up farming.")

     you@rice

     Term   kitty
     Shell  zsh
     Font   Fira Code
     Theme  gruvbox
